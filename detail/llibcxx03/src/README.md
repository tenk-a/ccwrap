# llibcxx03/src

Out-of-line source files for the ccwrap llibcxx03 C++ standard library (the
libc++-based tree for compilers whose own C++ stdlib is unusable, e.g. Open
Watcom). Mirrors libc++'s `libcxx/src` layout.

Currently the library is header-only (everything lives in `../include`); this
directory is reserved for future translation-unit-level sources.
